# 51 — The model picker offers no options the model supports

> _This was generated by AI during triage._

**What to build:** `ProviderModel.capabilities`, so the traits picker can offer
reasoning effort, fast mode and thinking.

**Status:** ready-for-agent

**Found by:** the 2026-07-28 parity audit, ledger R7.

## What happens

`ProviderModel.capabilities` is hardcoded `None`. The traits picker reads it and,
finding nothing, shows no reasoning-effort control, no fast-mode toggle and no
thinking control. The developer cannot ask for any of them.

## The stale note

`crate::config` currently says this holds _"until the ticket that sends a turn can
honour them"_. **That ticket has shipped.** The comment is stale and should be
deleted rather than preserved — this is now simply missing, not deferred.

## What upstream maps

`ClaudeAdapter` maps model capabilities onto three things:

- `effort` — a reasoning-effort level. Note the value `ultracode` maps to `xhigh`;
  the names on the wire and the names the CLI takes are not the same set.
- `settings.fastMode`
- `settings.alwaysThinkingEnabled`

Read the mapping there rather than inventing one — the client renders against
those exact names.

## Key interfaces

- `ProviderModel.capabilities` in whatever `crate::config` publishes as the model
  table. The table is already gated on CLI version (ticket 09), which is the right
  place to gate capabilities too: a capability the installed `claude` does not
  support should not be offered.
- Whatever `crate::agent` assembles for a turn needs to carry the chosen values
  through to the CLI. Check `--help` for the installed version before assuming a
  flag exists; this project has already been caught once by an SDK option the
  binary does not expose (see 62).

## Acceptance

- [ ] The traits picker offers reasoning effort, fast mode and thinking for a
      model that supports them.
- [ ] Choosing a value changes what the CLI is invoked with — verified against the
      real binary, not only against a fixture.
- [ ] A model that does not support a capability does not offer it.
- [ ] An installed `claude` too old for a capability does not offer it, consistent
      with how the model table is already gated.
- [ ] The stale comment in `crate::config` is gone.

## Out of scope

- `launchArgs` and the other unsent query options — 52.
- Persisting the choice across turns is 41's territory if it goes through the
  thread settings path; check before duplicating it.
