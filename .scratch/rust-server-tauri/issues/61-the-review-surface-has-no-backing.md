# 61 — The review surface has no backing

> _This was generated by AI during triage._

**What to build:** `review.getDiffPreview`.

**Status:** ready-for-agent

**Found by:** the 2026-07-28 parity audit, ledger M14.

## What happens

`review.getDiffPreview` is unimplemented, so the review surface has nothing to
draw.

## Why this is mostly already built

The diff arithmetic exists and is tested. Ticket 20 delivered turn diffs and
thread diffs from checkpoints, and the checkpoint diff range arithmetic —
**including `ignoreWhitespace`, which is honoured** — was verified during the
parity audit as matching upstream. So the hard part, which is deciding _which two
states to diff_, is done.

What is missing is the method that hands a preview to this particular surface,
and whatever shape difference exists between it and the diff paths already
serving the turn and thread views.

## Key interfaces

- `review.getDiffPreview` — read its request and response shape from the contract
  first. The question that decides the size of this ticket is whether it wants the
  same range arithmetic the checkpoint diffs already use, or a different range
  (working tree against a base, say). If it is the former, this is a thin adapter.
  If it is the latter, say so on this ticket before building.
- The existing checkpoint diff paths in `crate::git`. Reuse them; a second
  implementation of range selection is how `ignoreWhitespace` gets honoured in one
  place and not the other.

## Acceptance

- [ ] The review surface renders a diff.
- [ ] `ignoreWhitespace` is honoured, consistently with the turn and thread diffs.
- [ ] A large diff does not block the socket — check against whatever bound the
      existing diff paths already use rather than inventing a second one.
- [ ] Binary files, renames and deletions render sensibly rather than erroring.
- [ ] An empty diff renders an empty state.
- [ ] A project that is not a git repository refuses with a tag the method's own
      error union declares (see 39).

## Out of scope

- Any hosted review — PRs, comments, approvals (spec exclusion).
- Changing the turn or thread diff surfaces, which work.
