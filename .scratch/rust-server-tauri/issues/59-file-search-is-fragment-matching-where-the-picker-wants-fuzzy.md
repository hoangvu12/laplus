# 59 — File search is fragment matching where the picker wants fuzzy

> _This was generated by AI during triage._

**What to build:** ranked fuzzy matching for the file search that backs the
`@`-mention picker.

**Status:** ready-for-agent

**Found by:** the 2026-07-28 parity audit, ledger R13.

## What happens

`crate::filesystem` scans and matches **path fragments**. Upstream runs a real
fuzzy finder — `@ff-labs/fff-node`'s `FileFinder` over a 25,000-entry index with a
15-second scan budget and a 15-minute idle TTL.

The divergence is **declared** in `crate::filesystem`, so this is a known
simplification rather than an oversight. The measurement that makes it worth
revisiting is _where_ it shows:

- For a **literal** query the two give the same results. Nobody notices.
- For the **`@`-mention picker**, ranking is the entire point. Typing `cmpsr` to
  reach `ChatComposer.tsx` works upstream and returns nothing here. So does any
  initialism, any typo, and any subsequence that is not a contiguous fragment.

## Key interfaces

- The search entry point in `crate::filesystem` — matching and ranking, which are
  currently the same step and probably should not be.
- The scan side already exists (ticket 08's watcher and tree). Whether an index
  with a budget and a TTL is needed, or whether the existing scan is enough at
  laplus's scale, is a judgement to make with a real repository in front of you —
  upstream's 25,000-entry cap and 15s budget are the numbers to beat, not
  necessarily to copy.

## What to be careful about

Do not add a dependency to get this without checking what it costs the artifact.
This project exists for a size number — 5.05 MB download, measured by the build —
and `cargo xtask release` writes `docs/artifact-size.md`. A fuzzy matcher is a
small crate and should be fine, but **measure before and after** rather than
assuming, and put the figure in the commit.

## Acceptance

- [ ] A subsequence query (`cmpsr` → `ChatComposer.tsx`) matches.
- [ ] Results are ranked, with earlier and more contiguous matches first, and
      basename matches beating path matches.
- [ ] Literal-fragment queries return what they return today, in at least as good
      an order.
- [ ] The picker stays responsive on a large repository — state the repository and
      the entry count used to check.
- [ ] Ignore-file semantics (ticket 25) are unchanged; a fuzzy matcher must not
      start returning ignored files.
- [ ] The artifact size delta is measured and recorded.

## Out of scope

- Changing the tree browser, which is a different surface with different needs.
- Content search. This is filename matching only.
