# 50 — A session cannot be stopped, only a turn interrupted

> _This was generated by AI during triage._

**What to build:** `thread.session.stop` — ending the agent process from the UI.

**Status:** ready-for-agent

**Found by:** the 2026-07-28 parity audit, ledger M6; spec from the decider
audit §4.

## What happens

Interrupting a mid-turn is implemented and works (ticket 14). Ending the _session_
— stopping the agent process while leaving the conversation intact — is refused.

## Why this is close to free

Upstream's handler is a bare `requireThread` followed by a
`thread.session-stop-requested` event; all the work is in the reactor.

For laplus, `crate::threads` **already owns session teardown** for the interrupt
and restart paths. This is a command that reaches existing machinery, not new
machinery.

## Key interfaces

- `thread.session.stop` — a command, currently unparsed.
- Reuse the existing teardown. If the interrupt path and the restart path already
  differ in how they end a session, this ticket is a good moment to say which one
  is the general case rather than adding a third.
- The published session state must settle to something the composer draws as
  "no session" rather than as "running" — see the note below.

## The state afterwards

A thread with a stopped session is not a broken thread: the transcript stays, and
the next prompt should start a fresh session and resume the conversation the way a
restart already does. Check what the composer draws for a thread in that state
before declaring this done — the pane-with-no-session case has bitten this project
before (see ticket 35's second comment, where `derivePhase(null)` rendered a pane
with no working state at all).

## Acceptance

- [ ] Stopping a session ends the agent process. Verified by the process being
      gone, not only by the UI saying so.
- [ ] The conversation and its transcript are intact afterwards.
- [ ] Sending a new prompt after a stop starts a fresh session and continues the
      conversation.
- [ ] Stopping a session with no running agent is a no-op, not an error.
- [ ] Stopping mid-turn behaves sensibly — decide whether it implies an interrupt
      first, and say which in the commit.
- [ ] The pane does not render as disconnected or blank while stopped.

## Out of scope

- Deleting the conversation — 49.
- Interrupt, which already works.
